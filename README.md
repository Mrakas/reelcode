# ReelCodeBench project page

Static project page for *ReelCodeBench: Can Frontier LLMs Edit What They Rebuild?*
Served with GitHub Pages from the repository root (`index.html`). No build step is needed to view it.

- `index.html`, `assets/style.css`, `assets/app.js`: page, styles and interactions
- `assets/cases.js`: video case list (generated), `assets/tables.js`: leaderboard numbers parsed from the paper tables (generated)
- `static/videos/`: web-encoded clips (H.264, 640 px, 24 fps, no audio) with JPEG posters
- `static/images/`: paper figures (WebP), favicon and social preview image

To preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
